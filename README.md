# ॐ ANIME-EXPLORER

> **AnimeExplorer09** — *Explore. Watch. Discover.*

A mobile-first Progressive Web App (PWA) for discovering and exploring anime.

## Features

- 🔍 **Search Anime** — Find any anime by name
- 🔥 **Trending & Popular** — Browse top anime by popularity
- 📅 **Calendar** — Seasonal anime schedule
- 📰 **News** — Latest anime news
- 🗓️ **Watchlist** — Save anime to your personal watchlist
- 💬 **Chat** — Community chat
- 🗳️ **Polls** — Vote on anime polls
- 🖼️ **Image Search** — Search anime images
- 🛍️ **Store** — Anime merchandise
- 📱 **PWA Support** — Install as an app on your phone

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Auth:** Firebase Authentication (Google Sign-In)
- **API:** [Jikan API v4](https://jikan.moe/) (MyAnimeList data)
- **Hosting:** Vercel

## Getting Started

Just open `index.html` in a browser, or visit the deployed site.
